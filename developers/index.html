Certificate System

Every NIF file contains a CERT chunk that identifies the encoder and its license tier. Viewers check this chunk to decide whether to show the fumoca watermark.

How enforcement works: The CERT chunk (type 0x0020) is embedded at production time. It contains your encoder ID, license tier, and an HMAC-SHA256 signature using a key issued exclusively to your encoder. Fumoca viewers verify the signature before rendering without a watermark.
Certificate layout
BytesFieldDescription
0tierENCODER_TIER constant
1–32encoderIdASCII encoder identifier (issued by fumoca)
33–64licenseeIdASCII licensee name
65–68issuedAtUnix timestamp (uint32 BE)
69–72expiresAtUnix timestamp, 0 = never (uint32 BE)
73–104sigHMAC-SHA256 of bytes [0..72]
105–127reservedZero-padded
Signing a certificate (encoder SDK)
// JavaScript — encoder SDK import { NIFCertificate, ENCODER_TIER } from '@fumoca/nif-encoder'; const cert = await NIFCertificate.sign({ tier: ENCODER_TIER.DEVELOPER, encoderId: 'YOUR_ENCODER_ID', // issued by fumoca licenseeId: 'Your Company Name', issuedAt: Math.floor(Date.now() / 1000), expiresAt: 0, // 0 = never }, YOUR_HMAC_KEY); // 32-byte Uint8Array, issued by fumoca // Embed in your NIF file writer.add(CHUNK.CERT, cert.toUint8Array(), CODEC.RAW);
Verifying a certificate (reader)
// JavaScript — reading a NIF file import { NIFReader, ENCODER_TIER } from 'https://fumoca.co.za/sdk/nif-spec.js'; const reader = new NIFReader(arrayBuffer); const tier = reader.getEncoderTier(); if (tier === ENCODER_TIER.UNCERTIFIED) { // Show watermark or restrict features showWatermark(); }
Viewer SDK

The fumoca viewer SDK renders NIF files with the full cinematic experience — EWA splatting, 4-stage transition, layer system, depth-of-field, parallax, and WebGL2 optimisation.

The public spec lets you build a basic reader. The viewer SDK gives you the production-grade renderer, the cinematic entry transition, the scene editor integration, and all vertical-specific features — without months of WebGL development.

Embed API

Add an interactive NIF viewer to any webpage with a single script tag.

Basic embed
<!-- Add to your page --> <div data-nif-id="YOUR_NIF_UUID" data-nif-token="YOUR_LICENSE_KEY" style="width:100%;aspect-ratio:16/9"> </div> <script src="https://fumoca.co.za/sdk/embed/nif-viewer.js"></script>
JavaScript API
import { NIFViewer } from 'https://fumoca.co.za/sdk/embed/nif-viewer.js'; const viewer = new NIFViewer(container, { nifId: 'YOUR_NIF_UUID', licenseKey: 'YOUR_LICENSE_KEY', api: 'https://api.fumoca.co.za', autoplay: true, }); await viewer.load(); // Events viewer.onReady = ({ nifId, vertical, gaussianCount }) => {}; viewer.onError = (err) => {}; // Methods viewer.getEncoderTier(); // ENCODER_TIER constant viewer.setLayer('foreground'); viewer.enableParallax(true); viewer.destroy();
